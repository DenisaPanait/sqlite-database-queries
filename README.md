# SQLite Database Queries Project

## Overview
This project demonstrates the use of SQL and SQLite to query, filter, and analyze data from a database. It focuses on writing structured queries to retrieve meaningful information.

## Features
- Basic SELECT queries
- Filtering using WHERE clauses
- Sorting results with ORDER BY
- Aggregating data using COUNT, SUM, or AVG
- Working with tables and structured datasets

## Technologies Used
- SQL
- SQLite

## How to Run
1. Open the database file using SQLite or DB Browser for SQLite
2. Run the provided SQL queries
3. View the output results in the query tab
